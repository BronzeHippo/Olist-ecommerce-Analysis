# Olist E-Commerce Analysis

## Project Overview
Analysis of the Brazilian Olist e-commerce dataset using SQL, Python, Excel and Tableau 
to uncover insights about revenue trends, customer behaviour, seller performance 
and delivery efficiency.

## Tools Used
- **MySQL** — Data querying and analysis
- **Python** — Data cleaning and visualization (pandas, matplotlib, seaborn)
- **Excel** — Dashboard and pivot table analysis
- **Tableau** — Interactive dashboard

## Key Findings
- Total Revenue: R$15,422,462 from 96,477 delivered orders
- Top product category: Beleza Saude with R$1,456,027 in revenue
- Credit card is the dominant payment method at 76.4%
- 8.1% of orders were delivered late
- Late deliveries average a review score of 2.9 vs 4.2 for on-time deliveries
- São Paulo state has the most customers at 41,731

## Project Structure
